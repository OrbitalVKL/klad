Klad

Клад, « trésor enfoui » : carnet de comptes personnel pour Android. Les données restent sur le téléphone.

Données chiffrées, verrou par code ou empreinte

Connexion bancaire en lecture seule via Enable Banking, avec votre propre clé d'application. Aucun serveur Klad : l'appli parle directement à l'API. Sur le téléphone, la clé et les opérations sont chiffrées.

Télécharger l'APK
Adresse de retour à déclarer chez Enable Banking

Mise en place
  1. Dans le Control Panel Enable Banking, ajouter l'adresse de retour ci-dessus à votre application.
  2. Installer l'APK (autoriser l'installation depuis le navigateur).
  3. Créer le code à 6 chiffres et recopier sur papier la phrase de récupération : elle seule permet de restaurer une sauvegarde.
  4. Dans Klad : saisir l'identifiant d'application et choisir le fichier de clé privée .pem, puis « Tester la clé ».
  5. Charger les banques, connecter, puis « Récupérer » sur chaque compte.
